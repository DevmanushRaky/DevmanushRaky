## About Me

I'm an **AI-focused Full-Stack Developer** who builds production-ready web apps, mobile apps, and AI automation systems. I work across the full stack — from React/Next.js frontends and Flutter mobile apps to Node.js/TypeScript APIs with Supabase and Firebase, and AWS GPU infrastructure for LLMs.

- Building AI agents, automation pipelines, and content generation systems
- Deploying LLMs on AWS EC2 GPU instances using vLLM
- Shipping mobile apps with React Native & Flutter
- Working with startups and freelance clients globally via Upwork
- Currently deep in: **AI Agents, RAG systems, and LLM infrastructure**
